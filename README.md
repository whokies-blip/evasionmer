# evasionmer
ASMR 3D PLAGE

Une plage paisible en 3D dans le navigateur (Three.js, sons 100 % synthétisés, voix pré-enregistrées).

- Lancer en local : `python3 -m http.server` puis ouvrir http://localhost:8000
- `main.js` charge `app.js` (le monde), `extras.js` (activités), `world2.js` (village, personnes, bateaux), `world3.js` (volley, animaux, serveur), `world4.js` (personnages détaillés, voix, sons de l'eau).
- Voix générées avec [Piper](https://github.com/rhasspy/piper) — voix françaises SIWIS et MLS, licence CC BY 4.0.
